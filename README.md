## Охрана труда: эксперт по оценке профессиональных рисков

- [`prompts/ot-op-risk-expert.md`](prompts/ot-op-risk-expert.md) — готовый системный
  промпт ассистента-эксперта по охране труда и оценке профессиональных рисков (ОПР):
  роль, правила цитирования НПА, методология ОПР (матрица вероятность × тяжесть,
  иерархия мер, остаточный риск), шаблоны документов, режимы работы, чек-лист
  самопроверки. Нормативная база зашита по состоянию на **07.10.2026**.
