## Финансирование, контроль исполнения и отчётность

| Вопрос | Решение |
|---|---|
| Источник финансирования | Средства на охрану труда — не менее 0,2 % суммы затрат на производство продукции (работ, услуг) (ст. 226 ТК РФ); экономия взносов СФР на предупредительные меры (заявление — **до 15 ноября**) |
| Контроль исполнения | Ежемесячно — по мероприятиям блока 1; ежеквартально — по блоку 2; 1 раз в полгода — по блоку 3 |
| Отчётность | Акт выполнения мероприятия (накладные, акты выполненных работ, фотофиксация, протоколы испытаний), отчёт о выполнении Плана — ежеквартально руководителю |
| Приёмка выполненных мероприятий | Комиссия с участием ответственного за охрану труда; подтверждение снижения уровня риска — пересчёт УР в Карте рисков |
| При превышении сметы либо невозможности снизить риск | Временное ограничение работ, перевод на другой режим, при критическом риске — приостановка по ст. 214.1 и 216.1 ТК РФ |
