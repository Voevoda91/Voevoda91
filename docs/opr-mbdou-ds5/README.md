## 4. Методика (единая для всех трёх отчётов)

Матричный метод с балльной оценкой (приказ Минтруда России от 28.12.2021 № 926,
разд. 4.1.2) + контрольные листы (приложения к № 926). Для работ в
электроустановках, с газоиспользующим оборудованием, на высоте и для всех
опасностей с тяжестью последствий 4 балла и более — экспертный метод с анализом
сценариев.

- **В** — вероятность, 1…4 (крайне маловероятно … весьма вероятно);
- **Т** — тяжесть последствий, 1…5 (микротравма … групповая гибель);
- **УР = В × Т**: 1–3 низкий (приемлемый); 4–7 средний (умеренный);
  8–12 высокий (неприемлемый); 13–20 критический (недопустимый);
- иерархия мер: исключение → замена → инженерные → административные → СИЗ;
- обозначения мер в карте: `[И]` обучение, `[Т]` техническая, `[А]` административная,
  `[СИЗ]` средства защиты.

Полные шкалы, матрица и правила реагирования — в разделе 3 файла
`00-opis-komplekta-i-metodika.md` каждого корпуса.

## 5. Что нужно заполнить перед утверждением

1. Ф. И. О. руководителя, членов комиссии, ответственных лиц; должность
   председателя комиссии (заведующий либо заведующий хозяйством — по штату
   корпуса).
2. Даты и номера приказов, протоколов комиссии.
3. Фактическую численность по штатному расписанию (в таблицах уже проставлены
   данные из переданных PDF; при изменении штата пересчитать графы
   «Численность, чел.» и итоги).
4. Суммы сметы по мероприятиям Плана и общий бюджет (ст. 226 ТК РФ — не менее
   0,2 % затрат), заявку в СФР — до 15 ноября.
5. Базовые значения показателей результативности (графа «Базовое значение
   (2026)» в файле `06-…`) — по данным журналов НС, микротравм, листков
   нетрудоспособности и кадровой статистики за предыдущий год.
6. Даты ознакомления работников и подписи в листах ознакомления.
7. Перед утверждением проверить редакции НПА на pravo.gov.ru / consultant.ru
   (особенно сроки действия ПОТ — приказ Минтруда России от 29.04.2025 № 287н)
   и наличие обновлённых СанПиН для дошкольных организаций.

> Материалы подготовлены как рабочий комплект документов СУОТ. Оценка баллов
> выполнена комиссией (простым большинством голосов) по фактическим условиям
> каждого корпуса; при изменении условий труда, штата или законодательства
> карта рисков пересматривается внепланово (раздел 7 Положения).
