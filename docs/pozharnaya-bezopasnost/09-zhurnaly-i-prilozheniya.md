# ЖУРНАЛЫ, ФОРМЫ ДОКУМЕНТОВ И ПРИЛОЖЕНИЯ
## по пожарной безопасности объектов защиты

К комплекту инструкций о мерах пожарной безопасности для
административного здания (3 этажа), цеха розлива вина, склада
готовой продукции, цеха виноматериалов и вина, центрального
материального склада, цеха игристых вин.
